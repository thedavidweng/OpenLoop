## v0.1.1

Bug fixes and reliability improvements for model management.

### Fixes

- Fixed UI freeze (rainbow cursor) when deleting models — deletion now runs asynchronously
- Added crash-safe model deletion via `.openloop-deleting` markers; partially deleted models are cleaned up on next app launch
- Download cancellation now cleans up partial `.openloop-part` files automatically
- Added "Clear partially downloaded files" option when downloads fail
- Added "Delete All Downloaded Models" to the Danger Zone in settings
- Fixed retry button having no effect after failed downloads
- Removed unused Sync Homebrew Cask job from release workflow
