# OpenLoop v0.2.1

## Improvements

- **CI hardening**: Added `cargo audit` to the CI pipeline for Rust dependency vulnerability scanning.
- **Release updater**: `latest.json` is now uploaded alongside the DMG so the in-app updater can detect new versions.
- **pnpm 11**: CI and release workflows updated from pnpm 10 to pnpm 11 to match the project's packageManager.
- **Component tests**: Added GenerationPanel component rendering tests with `@testing-library/user-event`.

## Fixes

- **Rust safety**: Replaced unsafe `.unwrap()` on `output_path` with proper error propagation in `files.rs`.
- **Documentation**: Updated implementation status, PRD, README, and release docs to accurately reflect v0.2.0.
- **Code formatting**: Reformatted frontend code and locale files with Prettier.

## Upgrade

```bash
brew update && brew upgrade --cask openloop
```

Or download the DMG from [GitHub Releases](https://github.com/thedavidweng/OpenLoop/releases).

### macOS Gatekeeper

The DMG is not signed or notarized, so Gatekeeper will block first launch. To bypass:

- **Right-click → Open** the app, then confirm in the prompt, or
- **`xattr -cr /Applications/OpenLoop.app`** to strip the quarantine attribute, or
- Use **Homebrew** (`brew install --cask openloop`), which sidesteps Gatekeeper entirely.
